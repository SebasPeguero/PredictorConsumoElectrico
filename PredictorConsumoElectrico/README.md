# ⚡ Predictor Mod - Energy Consumption Forecast

A modern web application designed to forecast household electricity consumption. Built with strict adherence to **Onion Architecture**, the system decouples complex mathematical prediction algorithms from the presentation layer.

### 🚀 Key Features:
* **Multiple Prediction Models:** Implements Simple Moving Average (SMA), Linear Regression, Percentage Variation, and Trend Detection.
* **Clean Architecture:** Separation of concerns using Core, Infrastructure, and UI layers with DTOs and ViewModels.
* **In-Memory State Management:** Utilizes the Singleton pattern to persist algorithm configurations across HTTP requests.
* **Modern UI/UX:** Responsive interface built with Bootstrap 5 and customized with Material Design 3 guidelines.

**Tech Stack:** C#, ASP.NET Core MVC, LINQ, Bootstrap 5.
